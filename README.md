
# Experiment 8: Structured vs. Unstructured LLM Output

## Aim
To learn how to prompt an LLM to generate structured and
unstructured responses and compare their readability.

## Problem Statement
Describe Python, Java, and C++ in two formats:
1. Unstructured paragraph
2. Structured Markdown table

## Tools and Technologies
- Python
- Google Gemini API
- Google Gen AI SDK
- Google Colab

## Methodology
1. Define the unstructured prompt.
2. Define the structured prompt.
3. Generate both responses using the same model and temperature.
4. Print both outputs.
5. Validate the required table columns and language rows.
6. Compare readability and clarity.

## Expected Results
The unstructured response explains the programming languages
in paragraph form. The structured response organizes their
typing systems, use cases, and difficulty levels in a table.

## Conclusion
Structured output makes information easier to compare and
retrieve, while unstructured output provides a more natural
explanation.

## How to Run
1. Install dependencies using:
   pip install -r requirements.txt
2. Configure your Gemini API key securely.
3. Run:
   python experiment.py
